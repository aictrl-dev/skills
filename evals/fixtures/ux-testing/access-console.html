Request access

Ask for access to a system you need for your work. Requests go to the resource owner.

Access policy. Access is granted for the minimum level needed and expires after 90 days unless renewed.

Production systems require approval from the resource owner and a second reviewer. Requests without a justification are declined automatically.

Admin access is only granted to named employees. Contractors may request read access through their sponsor.

All access is logged and included in the quarterly access review for the owning team.

If you no longer need access, ask the resource owner to revoke it so the next review stays short.
